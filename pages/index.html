核心能力

不是一个大模型硬扛，而是分工明确的智能体协作

记忆、技能与 MCP 工具各司其职——总控负责规划，子智能体负责执行，汇总智能体负责收口。

记忆系统

总控智能体把出发地、天数、预算与节奏抽取成上下文，交给地图、车票子智能体复用； 长期规则沉淀在 /memory/AGENTS.md，由 FilesystemBackend 以虚拟文件系统挂载，跨对话保留。

FilesystemBackend /memory/AGENTS.md virtual_mode

技能插件

地图子智能体按需装载 amap-lbs-skill v2.0.0：POI 关键词与周边搜索、 步行/驾车/骑行/公交路径规划、旅游路线生成与热力图可视化。识别到「搜、找、附近、路线、规划」 等意图自动触发，凭证通过 AMAP_WEBSERVICE_KEY 注入。

amap-lbs-skill POI / 路径规划 AMAP_WEBSERVICE_KEY

MCP 工具

车票子智能体通过 MultiServerMCPClient 以 streamable_http 接入 12306-mcp，启动时动态拉取工具清单，完成车次查询、票价分析与直达/中转建议。 只做规划与建议，不执行真实购票。

12306-mcp streamable_http get_tools()
